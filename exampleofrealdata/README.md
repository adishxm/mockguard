# Real-World Evaluation Dataset (`exampleofrealdata`)

This directory contains live, real-world benchmark data demonstrating **MockGuard** detecting AI-generated tests that test mocks rather than actual application behavior (HackMatrix Problem Statement #41).

---

## Directory Contents

- **`MOCKGUARD_VERIFICATION_REPORT.md`**: Complete analytical report of the evaluation, including side-by-side matrices, mutant survival breakdowns, AST static finding analysis, and Gemini advisory traces.
- **`your-project/`**: The complete production target application (`ecommerce-checkout-service`) featuring:
  - `src/services/checkout.ts`: The System Under Test (SUT) with realistic business rules, payment gateway calls, and domain event emissions.
  - `templates/checkout.weak.test.ts`: Shallow AI-generated test (only asserts on `toHaveBeenCalledWith`).
  - `templates/checkout.strong.test.ts`: Strong behavioral test (asserts on return value, `orderStatus === 'PAID'`, `isFulfilled === true`, and domain events).
  - `tests/checkout.test.ts`: The active test file.
  - `switch-tests.js`: Script to toggle between weak and strong test suites.
- **`mockguard-results/`**: Machine-readable JSON verification report (`first-run.json`) generated by MockGuard during the live execution.

---

## How to Replicate From MockGuard Root

### 1. Test the Weak AI Mock Suite (Default)
```bash
node dist/src/cli/index.js verify exampleofrealdata/your-project --max-mutants 5 --concurrency 1
```
- **Verdict**: `FAIL` (Exit code: 1)
- **Static Finding**: `[MEDIUM] CALL_ONLY_ASSERTION`
- **Mutation Score**: `20%` (1 killed, 4 survived)

### 2. Switch to Strong Behavioral Suite & Re-verify
```bash
node exampleofrealdata/your-project/switch-tests.js strong
node dist/src/cli/index.js verify exampleofrealdata/your-project --max-mutants 5 --concurrency 1
```
- **Verdict**: `PASS` (Exit code: 0)
- **Static Findings**: `0`
- **Mutation Score**: `100%` (5 killed, 0 survived)

### 3. Reset Back to Weak Suite
```bash
node exampleofrealdata/your-project/switch-tests.js weak
```
