# MockGuard Security Gate

- [ ] Tool never invokes package install as part of analysis.
- [ ] Test command is explicit and bounded.
- [ ] Output is capped and redacted where practical.
- [ ] Optional LLM receives no tool access.
- [ ] Unsupported content abstains.
- [ ] No arbitrary repository edits by default.
- [ ] Local execution is described as non-sandboxed unless a real sandbox is implemented.
