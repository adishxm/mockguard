# MockGuard Claims Register

## Approved now

- MockGuard targets PS #41.
- Mutation testing checks whether tests detect controlled production-code changes.
- MockGuard is designed as a TypeScript/Jest local-first CLI.
- The MVP distinguishes static suspicion from dynamic mutation evidence.
- Gemini, if enabled, is an optional advisory provider and not the verdict authority.

## Conditional after measurement

- MockGuard reduces review effort.
- MockGuard improves mutation score.
- MockGuard has a specific precision/recall value.
- Gemini suggestions improve verified mutation outcomes.
- Gemini reduces time-to-fix.

## Prohibited without new evidence

- MockGuard proves a codebase is correct.
- All mocks or AI-generated tests are bad.
- Gemini-certified tests are correct without independent verification.
- Gemini output is safe merely because provider safety filters exist.
- Universal language/framework coverage.
- Production-grade sandboxing.
