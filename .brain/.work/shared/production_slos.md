# MockGuard Production SLO Candidates

These are operational candidates, not achieved results. Calibrate them using the final benchmark and supported project classes.

- Report generation success: measure per supported project shape.
- Baseline classification accuracy: target 100% on controlled fixtures.
- No orphaned child process after cancellation: target 100% in tests.
- Schema-valid reports: target 100% for supported runs.
- Reproducible fixture output: target 100% excluding timestamps.
- Diagnostic completeness: every failed run has a failure ID and replay metadata.
- Release artifact integrity: package contents match the allowlist.
