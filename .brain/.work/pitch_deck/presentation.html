SLIDE 02 / 08 • THE ROOT CAUSE

Coverage is Execution, Not Verification

Why traditional test metrics fail to catch mock-centered test suites.

1. Line Execution

Code coverage only records whether the JavaScript runtime stepped over a line of code. It offers zero proof that an assertion would fail if that line were wrong.

2. Mock Echoing

AI assistants configure mocks with synthetic fixtures and assert that exact return value. The test is essentially verifying Jest's own mock engine!

3. Mutation Proof

The only mathematical proof of test efficacy is a counterfactual mutation: corrupting production logic and verifying that tests fail (killing the mutant).

A local-first developer tool and CI guardrail built for HackMatrix PS #41.

Static AST Pattern Scan

  • Detects MOCKED_SUT (target service itself is mocked)
  • Detects CALL_ONLY_ASSERTION (asserts mock invocation only)
  • Detects NO_ASSERTION and MOCK_ASSERTION
  • Conservative confidence scoring without guessing

Deterministic Mutation Engine

  • 4 Deterministic AST Operators: Boolean flips, comparisons, boundaries, and primitive returns
  • Isolated Sandboxing: Original files remain 100% untouched
