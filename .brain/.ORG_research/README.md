# MockGuard original research archive

This directory preserves the original materials supplied for MockGuard/PS #41. Files under `attachments/` are source inputs and must not be silently edited. Derived summaries, evidence maps, and decisions are kept beside them.

## Contents

- `attachments/`: all six supplied files copied from the latest `MockGuard.zip`.
- `attachment_manifest.csv`: filename, type, purpose, and handling status.
- `evidence_register.md`: claim-to-source map and evidence quality.
- `research_notes.md`: production-grade interpretation of the supplied research.
- `source_snapshots.md`: external official sources consulted for production planning.
- `open_questions.md`: claims and design choices requiring implementation verification.

## Handling rules

1. Treat supplied research as evidence or design according to the label in the derived notes.
2. Do not present blueprint targets as completed measurements.
3. Record any correction in `.brain/UPGRADE_CHANGELOG.md` and the decision log.
4. If a source is replaced, preserve the earlier file and record why.
5. Do not include secrets, private repositories, or credentials in this archive.
